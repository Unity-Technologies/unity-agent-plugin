# Using Unity

Unity's skills live in this skill's `references/` folder. They aren't listed individually, so this index is the only way to reach them.

## Step 1: Pick one skill

Read the request, then scan the index below for the skill whose description fits it most exactly. Prefer the skill that covers the whole request; choose a narrower skill only when the request is specifically about its topic.

## Step 2: Read it and follow it

Read the chosen skill's file with the Read tool (paths are relative to this skill's folder) and follow its instructions. Don't answer from memory when a skill covers the request, because these skills are newer and more specific than training data.

A skill's own files are in its folder, `references/<name>/`. When the skill gives a path relative to itself, such as `scripts/…` or `references/…`, or names its skill directory or base directory (for example `<SKILL_DIR>`), that means its folder, not this skill's. Use the folder's full path in commands.

## Skills named by another skill

A skill may tell you to use, load or check for another skill by name, for example "use the `unity-cli` skill" or "check that `ui` is in your client's skills". Every skill in the index below is installed with this one, though only `using-unity` is listed in your client's skills. Treat each of them as available: when a skill names one, read its file from the index and follow it, and don't offer to install it. Where a skill's files mention its `SKILL.md`, that is its `<name>.md` file here.
